# Retail Analysis Dashboard

An interactive Power BI dashboard exploring sales trends, product performance, and customer demographics for a retail business.

## Dataset
[Retail Sales Dataset (Kaggle)](https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset) — a synthetic dataset simulating a retail environment, including Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit, and Total Amount.

## Tools Used
- Power BI (data modeling, DAX, visualization)
- DAX aggregations for KPI cards and category-level metrics

## Key Insights
- **Electronics generates the highest revenue (£157K)** despite Clothing selling more units (894 vs 849) — driven by a higher price per unit in Electronics.
- **Revenue split by gender is nearly even** (49% Male, 51% Female), suggesting broad appeal across the customer base rather than a gender-skewed market.
- Total revenue across the period: **£456K** from **3K units sold** across **1K customers**.
